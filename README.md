# RemCheck AI

An AI-powered Resume Analyzer platform that helps users understand why their resumes get rejected and how to improve them for better ATS performance and job matching using AI-powered ATS analysis.

---

# 🚀 Features

- 📄 Resume Upload & Parsing
- 🤖 AI Resume Analysis
- 🎯 Job Description Matching
- 📊 ATS Score Generation
- 🔍 Skills Gap Detection
- 🛠 Resume Improvement Suggestions
- 🔐 Authentication & Authorization
- 📁 Resume History Dashboard
- ⚡ Modern Responsive UI
- ☁️ Full Stack Cloud Deployment

---

# 🛠 Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Vite
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- Supabase
- Gemini AI API
- JWT Authentication
- Multer

## Deployment
- Vercel (Frontend)
- Render (Backend)

⚡ Installation Guide
1️⃣ Clone Repository
git clone https://github.com/ArrpitShah/Ai-Resume-Analyzer-.git

2️⃣ Go To Project Folder
cd Ai-Resume-Analyzer-

🔧 Backend Setup
Go To Backend Folder
cd backend

Install Dependencies
npm install

Create .env File
Create a .env file inside backend folder.
PORT=5000GEMINI_API_KEY=your_gemini_api_keySUPABASE_URL=your_supabase_urlSUPABASE_ANON_KEY=your_supabase_anon_keyJWT_SECRET=your_secret_key

Run Backend Server
npm run dev
Backend runs on:
http://localhost:5000

💻 Frontend Setup
Open New Terminal
cd frontend

Install Dependencies
npm install

Create .env File
VITE_API_URL=http://localhost:5000

Run Frontend
npm run dev
Frontend runs on:
http://localhost:5173
